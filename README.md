# Wispr Flow — Product Analytics & Funnel Intelligence Dashboard

An interactive product analytics and real-time funnel intelligence dashboard built for [Wispr Flow]. This project tracks user activation loops, cross-platform engagement, workflow distributions, monetization conversion simulators, and cohort retention matrices for AI-powered voice dictation.

---

## 📊 Core Metrics & Features

* **Active Users Ratio:** Tracks daily active users (**DAU: 20.1k**) against monthly active users (**MAU: 43.5k**) yielding a **46.2%** engagement ratio.
* **Onboarding Activation Funnel:** Step-by-step conversion tracking from initial app download (100%) through launch, mic permissions, to the first active dictation session.
* **Speed-to-First-Dictation:** Measures post-installation elapsed time, highlighting that users who dictate within $<2$ minutes achieve a **3.2x higher 30-day retention rate**.
* **Dictation Context Breakdown:** Analyzes voice utility across workflows (Messaging, Dev Environments, and Email/Docs).
* **Multi-Homing Score:** Evaluates cross-device synchronization and stickiness boosts (e.g., macOS + iOS co-active usage yielding strong LTV multipliers).
* **Free-to-Pro Monetization Simulator:** Interactive probability calculator modeling upgrade drivers based on word-count thresholds (e.g., 2,000-word soft caps) and specialty triggers like Whisper Mode.
* **Cohort Retention Matrix:** Weekly tracking matrix filtered by primary voice modes (Auto-Edit, Raw Dictation, and Whisper Mode).
